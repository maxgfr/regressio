# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite with vanilla TypeScript, SVG, and CSS. Bun remains the project package manager and task runner.

## Users

Developers evaluating or maintaining regressio from GitHub or npm.

## Product Purpose

regressio provides zero-dependency TypeScript regression, classification, statistics, diagnostics, preprocessing, prediction intervals, and matrix tools. Its public site lets developers see every runtime capability execute in a real browser and inspect the results visually.

## Positioning

The same browser session demonstrates the pure TypeScript API and the optional Rust/WASM acceleration path without server-side computation.

## Operating Context

Visitors arrive from GitHub or npm, scan an automatic health dashboard, then open interactive labs for model families and utility functions.

## Capabilities and Constraints

- Public static deployment under the GitHub Pages repository subpath.
- English interface.
- Dashboard plus interactive labs.
- Every public runtime export and public class method has a deterministic demonstration.
- Synthetic datasets are labeled.
- No runtime framework dependency.

## Evidence on Hand

The repository README, automated tests, generated TypeScript declarations, and browser-compatible ESM/WASM build are the factual sources. There are no customer, benchmark, or performance claims.

## Product Principles

- Show computed evidence before explanation.
- Make failures local, legible, and reproducible.
- Keep examples deterministic and technically honest.
- Preserve the library's dependency-light character.

## Accessibility & Inclusion

Target WCAG 2.2 AA with keyboard operation, reduced-motion support, and status cues that do not rely on color alone.
